# Erkennungsserver für „Noten scannen“

Der Erkennungsserver läuft als Hugging Face Space im Konto jpascher: https://huggingface.co/spaces/jpascher/notenerkennung (Adresse für den Wandler: https://jpascher-notenerkennung.hf.space, in index.html als `OMR_URL` eingetragen). Er wandelt Fotos oder PDFs gedruckter Noten mit homr in MusicXML um. Im Wandler erscheint er im Dialog „📷 Noten scannen …“ nach dem Häkchen „Verstanden“ als „Erkennungsserver des Wandlers“; die erkannten Noten werden gleich geladen.

Die vier Dateien in diesem Ordner sind genau das, was im Space liegt: app.py (Gradio-Oberfläche und Schnittstelle „scan“), omr_core.py (Erkennung, PDF-Seiten mit PyMuPDF in Bilder, Takte mehrerer Seiten hintereinander), requirements.txt (homr ab 0.7, pymupdf, spaces) und README.md (Kopf für Hugging Face: Gradio 6.31, Python 3.12, Lizenz AGPL-3.0). Ändert man eine davon, lädt man sie im Space unter „Files → Contribute → Upload files“ neu hoch; der Space baut sich dann selbst neu.

Hardware ist „ZeroGPU“, die einzige kostenlose Möglichkeit für Gradio-Spaces seit Juli 2026. homr rechnet aber auf der CPU, und die Erkennung läuft bewusst nicht in einer mit @spaces.GPU gekennzeichneten Funktion: So verbraucht sie kein GPU-Kontingent, das für anonyme Aufrufe sehr knapp ist (im ersten Versuch war es nach zwei Aufrufen erschöpft). ZeroGPU verlangt beim Start mindestens eine gekennzeichnete Funktion; dafür steht in app.py eine leere, die nie aufgerufen wird.

Erprobt am 2. November 2026 vom Wandler auf jpascher.github.io aus: Eine gesetzte Melodiezeile in G-Dur (8 Takte, Achtel, punktierte Halbe, Fis) kam vollständig richtig zurück, der erste Aufruf nach dem Start dauerte etwa 35 Sekunden (homr lädt dabei einmal seine Modelle, rund 37 MB). Eine kaputte Datei liefert eine Fehlermeldung statt Noten. Hochgeladene Dateien und Ergebnisse löscht Gradio nach spätestens einer Stunde. Ein Space, der 48 Stunden nicht benutzt wurde, schläft; der erste Aufruf danach braucht einige Minuten zum Aufwachen.

Für einen eigenen virtuellen Server gibt es im Unterordner vps eine Fassung ohne Hugging Face mit eigener Anleitung (vps/INSTALL.md); sie nutzt dieselbe omr_core.py. Der Wandler erkennt selbst, welche Art Server unter `OMR_URL` steht.
